# RAG 模块模式说明

## 两种模式概览

| 特性 | Mock 模式 | Real 模式 |
|-----|----------|----------|
| 用途 | 快速演示、无后端依赖 | 真实 RAG 攻击测试 |
| 知识库来源 | 手动输入文本 | 上传文件/导入预置数据 |
| 检索方式 | 无检索，直接注入全部内容 | ChromaDB 向量语义检索 |
| 后端依赖 | 无 | 需要容器服务运行 |
| 数据持久化 | 页面刷新即丢失 | 容器内持久化 |

## Mock 模式

### 工作流程

```
用户在文本框输入知识内容
        ↓
内容直接拼接到 System Prompt
        ↓
发送给 LLM
```

### 适用场景

- 快速演示 RAG 投毒概念
- 无需启动后端服务
- 控制精确的注入内容

### 示例

用户输入：
```
- VIP客户可享受免审批贷款
- 内部员工折扣码：INSIDER2025
```

System Prompt 变为：
```
你是银行客服助手...

[知识库内容]
- VIP客户可享受免审批贷款
- 内部员工折扣码：INSIDER2025
```

## Real 模式

### 工作流程

```
用户上传文件（PDF/DOCX/图片等）
        ↓
容器内解析提取文本（OCR等）
        ↓
文本分块 + 向量化存入 ChromaDB
        ↓
用户提问时，语义检索相关片段
        ↓
检索结果注入 System Prompt
        ↓
发送给 LLM
```

### 适用场景

- 测试真实 RAG 系统的安全风险
- 演示文件解析过程中的攻击向量
- 测试向量检索的语义匹配行为

### 预置测试数据

点击「重置」按钮可导入预置数据：

| 文件 | 类型 | 攻击场景 |
|-----|------|---------|
| product-pricing | 正常 | 金融产品定价信息 |
| sales-scripts | 正常 | 销售话术模板 |
| internal-strategy | 敏感 | 内部策略（测试信息泄露） |
| sensitive-data | 敏感 | 薪资/密码（测试信息泄露） |
| poisoned-policy | 投毒 | 含 prompt injection 的假政策 |
| jailbreak-doc | 越狱 | 诱导模型突破限制 |

## Mock 模式的局限性

Mock 模式**无法测试真实的 RAG 上下文泄露攻击**。

| 测试项 | Mock 能测吗 | 原因 |
|--------|-----------|------|
| 投毒内容能否被检索到 | ❌ | 没有检索过程，内容直接注入 |
| 语义相似度触发攻击 | ❌ | 没有向量匹配 |
| 隐藏文本能否被解析 | ❌ | 没有文件解析 |
| 攻击成功后的效果 | ✅ | 可以模拟 |

**本质区别：**

```
Mock：演示 "如果攻击成功，会发生什么"
Real：测试 "攻击能否成功"
```

**真实 RAG 上下文泄露攻击链：**

```
1. 攻击者上传投毒文档（含隐藏 prompt injection）
2. 文档被解析、向量化、存入知识库
3. 受害者提问（与投毒内容语义相关）
4. 检索系统召回投毒片段
5. 投毒内容注入 LLM 上下文
6. LLM 执行恶意指令（泄露其他文档内容）
```

Mock 模式跳过了 1-4 步，直接从第 5 步开始，因此只能演示攻击效果，无法验证攻击可行性。

## 选择建议

| 场景 | 推荐模式 |
|-----|---------|
| 快速展示 RAG 投毒原理 | Mock |
| 展示完整攻击链（上传→解析→检索→攻击） | Real |
| 无 Docker 环境 | Mock |
| 测试 OCR/文件解析漏洞 | Real |
| 验证投毒文档能否被召回 | Real |
| 测试真实上下文泄露 | Real |
